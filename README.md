# 🎓 University Quiz Master – Mobile App (Flutter)

A comprehensive quiz application built using **Flutter** and developed in **Visual Studio Code**. 


## 📱 App Overview

In this mobile app:

You select your academic year (1-4).  
You choose a specific course from your syllabus.  
You answer 5 questions with a 30-second timer each.  
You get instant feedback and your final score with grade.  
The app covers 16 courses with 80+ questions!


## 🛠️ Technologies Used

| Component          | Description                   |
|--------------------|-------------------------------|
| Flutter            | UI framework                  |
| Dart               | Core programming language     |
| Material Design    | For UI, icons, and components |
| VS Code            | Development environment       |
| Stateful Widgets   | For dynamic state management  |
| Timer              | For timed quiz questions      |
| Navigation         | For moving between screens    |
